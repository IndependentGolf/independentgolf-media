# independentgolf-media

## Bildregeln für Social Media

### Freigestellte Bilder (Ball/Produkt auf weißem Hintergrund)

Gilt nur für freigestellte Bilder – Fotos mit Hintergrund (See, Ballberge usw.) sind davon nicht betroffen.

- **Format 3:4, 1080 × 1440 px**, weißer Hintergrund. Instagram zeigt Profil-Vorschauen im Raster als 3:4 – so wird nichts abgeschnitten (die Vorschau lässt sich nachträglich nur hineinzoomen, nicht verkleinern).
- **Motiv mittig mit ca. 10 % Rand** rundherum (Balldurchmesser max. ca. 860 px). Logo bzw. Modellschriftzug („Pro V1“ o. ä.) muss vollständig in dieser Fläche liegen.
- Bild durch weiße Fläche erweitern, nicht das Motiv kleiner rechnen – der Ball bleibt in voller Auflösung scharf.
